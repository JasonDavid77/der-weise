# Werkzeug-Register

> Welche Wissenstraeger der Weise neben dem Speicher nutzen kann: verbundene
> MCP-Server, Fach-Datenbanken, Webseiten. Pflegt der Skill thema beim
> Quellen-Scan (Schritt A.6). Jede Zeile traegt, WIE sie gefunden wurde.
> Mit Python wird es per `learn-store.py --register` in den Speicher gelegt; ohne Python durchsucht der Weise die Datei direkt.
>
> Routing-Regel: Stabiles Wissen (Konzepte, Anleitungen) kommt in den Speicher.
> Volatiles (Rechtsprechung, Preise, laufende Aenderungen) wird NIE gespeichert,
> sondern live ueber das Werkzeug abgefragt ("Stand <Datum>").
