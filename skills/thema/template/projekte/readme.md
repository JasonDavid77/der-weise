# projekte/ -- je Projekt ein Ordner

Ein Projekt ist das Zielobjekt, an dem gelernt und gebaut wird. Ein Thema kann nacheinander mehrere
Projekte tragen; hoechstens eines ist aktiv (Zeile "Aktives Projekt:" in ../learner-state.md).

Je Projekt legt der Weise einen Ordner `<name>/` mit `projekt.md` an, sobald der Projektpfad
bestaetigt ist: Deliverable, Ablage, Status, die Tabelle Projektpfad (Konzept, Baustein, Bau-Stand)
und ein Log. In den Ordner kommt auch, was beim Bauen entsteht, wenn es keine eigene Ablage gibt.

Nicht gespeichert, nicht durchsucht. Vertrauliches gehoert nicht hierher: Bei echten Faellen steht
in `projekt.md` nur der Pfad zur eigenen Ablage und die Namen der Bausteine.
Uebungsdokumente liegen in ../uebungen/, ein Ordner fuer das ganze Thema.
