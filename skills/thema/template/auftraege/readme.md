# auftraege/ -- Richtung: der Weise -> die Person

Rechercheauftraege und Prompts fuer externe Tools (eigene Werkzeuge, etwa eine Fachdatenbank oder eine Websuche), dazu Bitten um Unterlagen.
Eine Datei pro Auftrag: `YYYY-MM-DD-<slug>.md`. Antworten gehoeren NICHT hierher,
sondern nach `../eingang/`. Erledigte Auftraege bleiben liegen (Historie).
