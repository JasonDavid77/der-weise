# auftraege/ -- Richtung: der Weise -> die Person

Rechercheauftraege (Prompts fuer Ihr eigenes Recherche-Werkzeug, etwa einen KI-Chat mit
Recherche-Funktion oder eine Fachdatenbank), dazu Bitten um Unterlagen. Eine Datei pro Auftrag:
`R<n>-YYYY-MM-DD-<slug>.md`. Die Nummer laeuft ueber das ganze Thema fort, das Datum zeigt den
Stand. Ergebnisse gehoeren NICHT hierher, sondern unter derselben Nummer nach `../eingang/`
(am besten als Markdown oder Text, etwa `R1.md`). Erledigte Auftraege bleiben liegen (Historie).

## Uebersicht

| Nr | Thema | Wofuer | Auftrag vom | Ergebnis vom | Eingangsdatei | Quelle | Stand |
|---|---|---|---|---|---|---|---|

Stand: offen / zurueck / eingearbeitet. Der Weise schreibt die Tabelle fort.
